# Security Toolkit Dashboard

A web-based cybersecurity toolkit built with Python and Flask.

## Live Demo
https://security-dashboard-77ul.onrender.com

## Tools
- **Password Checker** — checks password strength
- **Caesar Cipher** — encrypts and decrypts text
- **URL Analyzer** — analyzes URLs for suspicious patterns
- **Password Hashing** — hashes passwords using SHA256
- **Hash Identifier** — identifies hash type (MD5, SHA1, SHA256, SHA512)
- **Phishing Analyzer** — analyzes text for phishing indicators
- **Phishing Email Headers** — analyzes email headers for suspicious content
- **File Integrity Monitor** — verifies file integrity using SHA256

## Tech Stack
- Python 3
- Flask
- HTML/CSS
- hashlib, re, email (Python standard library)
